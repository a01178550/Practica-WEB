Acerca del Proyecto

Este proyecto es una maqueta funcional que simula un sistema con autenticación básica y una Pokédex conectada a la API pública de Pokémon.

Incluye:

  • Login funcional con validación demo
  • Protección de rutas con localStorage
  • Pokédex con búsqueda por nombre
  • Diseño moderno y responsivo

Actualmente es una versión demostrativa sin base de datos real.
